# Algorithm Viewer (WIP)

An extensible algorithm viewer with the ability to scrub forward and backwards through an algorithms execution.

## Implemented Algorithms
- Sorting algorithms
  - Bubble sort
  - Insertion sort
  - Bottom-up Heap sort
  - Merge sort
  - Quick sort
- Searching algorithms
  - Linear search
  - Binary search

## Controls
|Key|Control|
|---|---|
|1-7|Select algorithm|
|←/→|Step Backward/Forward|
|↑/↓|Change Step value|
|esc|Quit|
